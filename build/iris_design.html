透明过载 · v1.8 · 2026

一台靠电路把“透明”做成指标、同时能把 solo 撑起来的过载：输入与预提升两级把电平顶起来，低切搬出增益回路、与增益彻底解耦，两级削波用 8 只 4×1N4148 串成桥、每级 ±1.3 V 的 headroom，级间 −6 dB 让第二级重新有空间，干声经 BLEND 混回保住音头，TONE 只做高频高切。总增益 +12 … +38 dB。

为什么长成 v1.8Revision

这版不是一次设计出来的，而是六轮实测把一个“透明推子”逼成能弹 solo 的失真：v0.4 解决电平与低切耦合，v0.6 把削波阈值抬到 ±1.3 V 让音头回来，v1.0 加入级间衰减与第二级削波，v1.2 修掉求解器不收敛导致的“劈”，v1.3–1.7 试过交越死区与 8 倍过采样（都留下数据），v1.8 找到真凶：把硬限幅从 48 kHz 挪到过采样域。下面每一条都是可焊电路：

逐级设计Stage by Stage

01 · 输入级：高阻 + ×2

吉他拾音器是电感源，最怕被低阻负载拖掉高频，所以第一级必须是高阻输入；而只有 1× 缓冲又会让整机偏轻，于是这一级同时兼任 +6 dB：

A₁ = 1 + R3/R2 = 1 + 10K/10K = 2.0×（+6 dB）
输入阻抗 ≈ R1 = 1 MΩ；C1 22n + R1 1M 的高通 = 7.2 Hz

02 · 低切：放在级间，不碰增益

把 RV2+R4 串在增益级的地端，等于用低切去改增益公式的分母，低切一拧增益就跟着跑（实测联动 17 dB）。v0.4 起改成两级之间的无源高通：C2 串在信号里，RV2+R4 对地，后级 1M 输入让通带增益恒为 1：

f = 1 / (2π · (RV2 + R4) · C2)
RV2 = 0 → 1/(2π·5.1K·100n) = 312 Hz；RV2 = 50K → 1/(2π·55.1K·100n) = 28.9 Hz

03 · 预提升：2 kHz 以上 +7 dB

这是 v1.4 为了“金属芯感”加的：在削波之前把 2 kHz 以上抬 7 dB，等于让中高频先撞削波器 —— 泛音密度上来了，中低频还留着自己的动态：

平直段 A = 1 + R14/(R15) 的直流通路 = 1×
高频段 A ≈ 1 + 10K/8.2K = 2.2×（+7 dB），转折由 C9 10n × 8.2K ≈ 1.9 kHz 决定

04 · 削波级 1：桥式反并联 + 4.7K 软膝

非反相放大，反馈支路里放 RV1（变阻器），削波对跨在它两端。每侧两只 1N4148 串联，把阈值从 ±0.65 V 抬到 ±1.3 V；再串一只 4.7K 到二极管，拐角被磨圆：

A₂ = 1 + RV1/Rg1 = 1 + 100K/5.1K = 1 … 20.6×
阈值 = 2 × 0.65 V = ±1.3 V（每侧两只串联）

为什么必须抬阈值：v0.6 之前用一对 1N4148（±0.65 V），信号一旦过膝就变成恒定电平的方波，音头被抹平 —— 实测音头只比延音大 0.4 dB，听感就是“无音头的合成器”。抬到 ±1.3 V、再加级间衰减之后，音头−延音回到 8 dB 量级。

05 · 级间 −6 dB 与削波级 2

第一级削完，信号被钉在 ±1.3 V 附近；直接再放大就只会更方。所以先 R17/R18 分掉一半，让第二级重新拿到 headroom，再削一层 —— 两级叠加给出“多层谐波”而不是“一层方波”：

衰减 = R18/(R17+R18) = 10K/20K = 0.5（−6 dB）
第二级阈值同样 ±1.3 V，Rg2 5.1K，RV6 微调增益

06 · BLEND：干声混回音头

干声从预提升级之后取，绕过两级削波，经 RV5 100K 混到输出节点。BLEND 越大，音头与拨弦细节越多、声音越松；关小则更紧、更“贴脸”。这是这台机器在“透明”与“能打”之间唯一的连续旋钮。

湿声支路 = R21 22K → 混合点；干声支路 = RV5（0…100K）→ 混合点
BLEND = 0 时只剩湿声，= 100% 时干湿约各半（受 R21 与 RV5 的比值限制）

07 · TONE 与 VOLUME

TONE 不做串联低通，而是让 RV3 + C4 把高频对地泄掉：旋钮越大，对地阻抗越大、高频泄得越少，所以“顺时针变亮”，而且行程与人耳一致：

f = 1 / (2π · RV3 · C4)
RV3 = 1K → 34 kHz（几乎不切）；RV3 = 100K → 338 Hz（很暗）

音量用 100K A 型分压；C8 1µ 隔直放在电位器之前，碳膜上没有直流、不会“咔嗒”。

搭建与调试Build

  • 先把电源量对：U2 的 VOUT 应为约 −8.6 V；四个运放的 V+ 与 −9V 之间约 17 V。偏低先查 D9 方向与 C10 飞电容极性。
  • 静态工作点全是 0 V：这一版是双电源（±9 V）、**地参考**，所有运放输出静态都应在 0 V 附近，±30 mV 以内算正常。
  • 低切最小转折由 R4 定：RV2 拧到最小时只剩 5.1K，转折 312 Hz；想要更厚可把 R4 改 3.3K（约 480 Hz→更低），代价是低频进削波器。
  • 两级增益一起调：RV1 与 RV6 是串起来的：先把 RV6 置 0（第二级 1×），只用 RV1 找音色，再慢慢加 RV6 增加密度。
  • 软膝电阻是“手感”旋钮：R16/R20 从 4.7K 加到 10K，拐角更圆、更“绵”；减到 2.2K 会更硬更“扎”。
  • BLEND 决定“松/紧”：干声从预提升级后面取，绕开两级削波。solo 想要紧就关小，分解和弦想要呼吸感就开大。
四个常见的坑：
· ICL7660 的飞电容（C10）必须是电解且注意极性：接反会直接击穿，输出变成 −1 V 左右。
· 两颗 1N4148 串联是为了抬高阈值：单只只有 ±0.65 V，两级串起来才有 ±1.3 V 的 headroom；不要图省事只用一只。
· Rg1/Rg2 不要改小：它们决定每级的最大增益，改小会让 GAIN 全开时也削不出来。
· TONE 用电位器直接对地：RV3 一端接信号、一端经 C4 到地，接错成串联会变成低通而不是高切。
